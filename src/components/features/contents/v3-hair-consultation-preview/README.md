# v3 헤어컨설팅 앱 미리보기

콘텐츠 관리 v3 상세 모달의 상담 본문, 고객용 답변 카드 및 답변 상세를 표시합니다.

## 원본과 재사용 범위

`source/`는 `meemong-new-hair-consulting-web`의 다음 표시 컴포넌트와 그 의존 코드의 스냅샷입니다. 원본 리비전과 파일별 SHA-256은 `source-manifest.json`에 기록합니다.

- `question-information.tsx`: 간편 상담 본문·고객 정보, 심층 고객 정보·요청사항·진단 정보
- `customer-answer-card.tsx`: 고객에게 보이는 간편/심층 답변 카드
- `answer-detail.tsx`: 간편 답변·견적, 심층 얼굴형/앞머리/기장/컬/레이어 진단과 추천 시술
- 원본 타이포그래피·색상·반경·일러스트 및 사진 확대 UI

원본 프로젝트를 런타임 의존성으로 참조하지 않습니다. 이 저장소만으로 빌드·배포할 수 있습니다. 외부 웹페이지를 임베드하거나 고객 토큰을 전달하지 않으며, 관리자 조회 데이터를 `adapter.ts`에서 원본 표시 모델로 변환합니다.

## 관리자 적용 차이

- 원본 import 별칭과 정적 이미지 경로만 이 저장소 위치로 변경했습니다.
- `meemong-top-bar.tsx`의 고객 앱 라우터 기본 뒤로가기를 제거했습니다. 사진 뷰어는 자체 닫기 콜백을 사용합니다.
- `separator.tsx`는 같은 스타일의 단순 읽기 전용 divider로 연결해 별도 Radix 패키지 의존성을 피했습니다.
- 버튼 역할에 맞지 않는 텍스트 필드 트리거의 `aria-invalid`를 제거하고 기존 오류 설명 연결은 유지합니다.
- 사진 뷰어의 포커스/스크롤 잠금은 프레임의 `ownerDocument`를 사용합니다.
- 관리자 API가 제공하지 않는 디자이너 프로필 사진·지역·고객 열람시각은 추정하지 않습니다. 카드에서는 고객 열람 전 변형을 사용하며 관리자는 카드를 클릭해 전체 답변을 볼 수 있습니다. 고객용 구매·평가·채팅 API는 호출하지 않습니다.
- 상단 내비게이션은 관리자 미리보기용이며 본문은 원본 컴포넌트입니다. 상담·답변 미리보기 폭은 375px입니다.
- 목록 API에 없는 답변 이미지·디자이너 정보는 해당 답변 상세 쿼리로 조회합니다. 페이지 기본 크기는 10개이며 선택한 답변 패널도 같은 캐시를 사용합니다.

## 스타일 생성

원본 스타일을 iframe 문서 안에 격리해 관리자 전역 스타일과 섞이지 않게 합니다. React portal로 데이터를 전달하므로 민감한 내용이 iframe URL이나 메시지에 포함되지 않습니다.

`npm run build:hair-preview`는 `preview.css`와 원본 스타일/컴포넌트에서 `public/v3-hair-preview/preview.css`를 생성합니다. 생성 결과도 버전 관리하며, 개발·빌드 시에는 커밋된 CSS를 그대로 사용합니다. 미리보기 스타일·클래스 또는 Tailwind 버전을 변경할 때 이 명령을 실행하고 생성 결과를 함께 커밋합니다. 원본 스냅샷을 갱신할 때는 manifest와 이미지 경로도 함께 확인합니다.

`/v3-hair-preview/`는 인증 없이 제공하는 디자인 에셋 전용 경로입니다. 상담·답변 데이터나 인증 정보를 이 디렉터리에 저장하지 않습니다.
